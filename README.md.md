# Quiz Application in C

## Project Overview
The Quiz Application is a simple console-based project developed using the C programming language. It allows users to answer multiple-choice questions and calculates their final score based on their answers.

## Objectives
- To develop a basic quiz program using C.
- To understand conditional statements and loops.
- To practice user input and output.

## Features
- Multiple-choice questions.
- User-friendly console interface.
- Automatic score calculation.
- Displays the final result.

## Technologies Used
- C Programming Language
- Visual Studio Code
- GCC Compiler

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Compile the program using:

   `gcc Quiz.c -o quiz.exe`

4. Run the program:

   `quiz.exe`
